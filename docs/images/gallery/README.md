# Gallery image sources

The larger JPEGs and `thumbs/` images are generated documentation previews.
Rebuild and check them with `tools/gallery.py`; see `docs/gallery.md`.

Landscape and portrait photographs were supplied by the project owner and
approved for publication in the existing README. The synthetic chart is
original project test/example artwork, covered by the repository's MIT license.

`signature.png` is the owner's selected sample 3. Copyright remains with
the project owner; it is used with permission for these documentation examples
(approved 2026-11-06). The supplied lettering was preserved while white was
converted to transparency and empty space cropped. It is not a renderer asset
or an automatically added signature for users' photos.
