# Camera brand logos / Logo các hãng máy ảnh

PNG thumbnails (512 px wide, trimmed) rendered from Wikimedia Commons SVGs and
used by style C to mark the camera brand in the caption band. Rendered as-is:
never recolored, stretched, or combined into new marks.

All source files are published on Wikimedia Commons as **public domain**
(PD-textlogo: simple wordmarks/marks below the threshold of originality).
Trademark rights remain with the owners. These files are displayed only next
to photographs actually taken with that brand's equipment (nominative,
descriptive use), which is the same use Commons itself makes of them.

Brands without a Commons PD logo (e.g. SIGMA, DJI) fall back to a bold text
wordmark drawn by the renderer. The fallback also covers any brand whose logo
file is missing.

Fetched via the Commons API (server-side SVG→PNG rendering, `iiurlwidth=512`),
then trimmed to content and normalized to RGBA. Re-run the same API calls to
refresh; do not edit the artwork.
